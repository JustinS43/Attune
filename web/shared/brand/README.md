# Attune brand assets

The canonical Attune identity is the **01 Conversation** concept. Use these files in product interfaces, documentation, demos and exported materials:

- `attune-icon.svg` — square app icon or avatar
- `attune-mark.svg` — symbol without a background
- `attune-wordmark-light.svg` — wordmark for light surfaces
- `attune-wordmark-dark.svg` — wordmark for dark surfaces

The original explorations remain in `web/phone/branding/` as design history. Product code should reference the assets in this folder so a future brand update has one source of truth.
