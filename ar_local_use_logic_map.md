## Architectural Processing Stages

1. **Hardware Ingestion Engine:** The system binds to the Logitech webcam using OpenCV for raw video frames and PyAudio for multiplexed hardware audio blocks.
2. **Vision Spatial Target Isolation:** Local MediaPipe calculations isolate a single face target, outputting normalized frame coordinate bounds (X, Y) to calculate the directional orientation vectors.
3. **Cross-Platform OS Guardrail:** A runtime conditional wrapper detects the host system configuration:
   * **macOS:** Instantiates device links using CoreAudio infrastructure mapped directly to **BlackHole** drivers.
   * **Windows:** Instantiates device links using WASAPI loopback or MME parameters mapped to **VB-Cable** structures.
4. **Alango Audio Isolation:** The edge DSP layer takes raw sound packets and isolates the target voice block using spatial boundaries generated by the face tracking module. 
5. **Offline ASR Processing (Whisper Interface):** The network code block is eliminated. Raw, single-speaker PCM buffers are written straight to RAM queues where local quantized INT8 models (**Faster-Whisper** or **Whisper.cpp**) decode vocal patterns locally on the machine CPU/GPU.
6. **Dynamic HUD Renderer:** The output text string is anchored to the calculated target coordinate map. OpenCV draws a translucent text layout box floating natively behind the target speaker's face vector coordinates.
